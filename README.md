# Neural_Network-Iris
### Iris Neural Network Model:
This project implements a simple feedforward neural network using PyTorch to classify Iris flowers into three species: Setosa, Versicolor, and Virginica. The model takes four input features—sepal length, sepal width, petal length, and petal width—and passes them through two hidden layers with ReLU activation. The network is trained using supervised learning to minimize classification loss and demonstrates how basic neural networks can effectively solve multi-class classification problems on structured datasets.
